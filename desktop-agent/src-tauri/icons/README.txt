Coloque aqui os arquivos de ícone gerados pelo `cargo install tauri-cli` →
`npm run tauri icon path/para/logo.png`.

Arquivos esperados:
  32x32.png
  128x128.png
  128x128@2x.png
  icon.ico   (Windows)
  icon.icns  (macOS)

Sem esses arquivos o `tauri build` falha. Use o logo do HuskyPDV (1024x1024 PNG)
e gere todos com um comando só.
